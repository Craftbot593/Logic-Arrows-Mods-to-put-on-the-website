# Logic-Arrows-Mods-to-put-on-the-website
For more information, read the README extra document



To put the mods on Logic Arrows, you need to download the HTML archive. Next, you open your browser (In my case, Edge) and press F12, it will open the devs table. Now you go to the Sources table, you search "Page", and open the logic-arrows.io dominian. For last, search the archives with the last name .js
